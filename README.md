🚖 Ola Ride Booking Data Analysis Dashboard | Power BI Project
1.📌 Short Description / Purpose

An interactive Ola Ride Booking Analysis Dashboard built using Power BI to analyze booking trends, cancellation patterns, revenue distribution, and operational performance.

The purpose of this project is to transform raw ride booking data into meaningful business insights that help reduce cancellations, improve service efficiency, and support data-driven decision-making.

2.📊 Project Overview

This project focuses on analyzing extracted ride booking data to identify key performance indicators (KPIs) such as total bookings, cancellation rate, revenue trends, and ride category performance.

The dashboard provides a centralized view of operational metrics to help stakeholders quickly understand performance gaps and improvement areas.

3.🛠️ Technologies Used

Power BI Desktop – Dashboard development & data modeling

Power Query – Data cleaning and transformation (ETL)

DAX (Data Analysis Expressions) – KPI calculations & measures

File Format: .pbit (Power BI Template File)

Data Source: Extracted structured dataset (CSV/Excel format)

4.🎯 Business Problem

High booking cancellations affecting revenue and customer experience

Lack of visibility into driver vs customer cancellation trends

No centralized reporting for ride category performance

Difficulty identifying peak booking trends

5.🎯 Goal of the Dashboard

Track Total Bookings & Revenue

Calculate Cancellation Rate (%)

Analyze cancellation reasons

Identify top-performing ride categories

Monitor booking trends over time
